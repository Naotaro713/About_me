# NIKKI — 質問に答えるだけの日記

日記ルーチン（nikki-diary）を、ブラウザだけで動く単体アプリにした試作版です。`index.html` を開くだけで動きます。

## できること

| 画面 | 内容 |
|---|---|
| 書く | 質問に1問ずつ答える（フル版8問／短め3問）→ 下書きを確認 → 承認して保存。最初に昨日のToDoの結果を確認する |
| 記録 | 週ごとの一覧、キーワード検索、閲覧・編集・削除、.md の書き出し |
| 振り返り | 週次（記録日数・平均の調子・ToDo達成率・調子の推移・起業ログ）、月次、年間（ヒートマップ） |
| 設定 | 毎晩のリマインダー（.ics）、Obsidian 形式の ZIP 書き出し、用語の統一表、JSON バックアップ |

## 設計上の判断

- **データは端末内のみ**（localStorage）。サーバーなし、外部送信なし。
- **AI は内蔵しない**。フィードバックは「Claude への依頼文をコピー → 返答を貼り付け」で追記する。API キーをブラウザに置かないため。
- **出力は nikki-diary の様式に準拠**（`日記/YYYY-MM-DD週/YYYY-MM-DD.md`、末尾に週次レビューへのリンク）。

## 既知の制約

- ブラウザのデータを消すと日記も消える（定期的に JSON バックアップが必要）
- 通知はアプリ単体では送れないため、カレンダーのリマインダーで代替
- Obsidian との同期は一方向（アプリ → ZIP → vault）
